# v0.3.1 Feature Pack — Data Platform Foundation

## Added
- Enterprise Ingestion Hub frontend.
- CSV upload integration with FastAPI backend.
- Upload metadata database models.
- Dataset catalog models.
- CSV validation engine.
- Connector catalog API.
- Data Catalog and Data Explorer prototype screens.
- Sample valid and invalid order CSV files.

## Changed
- Application shell now includes Data Platform navigation.
- App version updated to v0.3.1 in the UI and API metadata.

## Known Limitations
- Tables are created automatically on startup for local development. Alembic migrations should replace this before production hardening.
- Uploaded CSV records are validated and stored as files; canonical order/trade persistence is planned for Pack 3.2.
- Authentication is not yet enforced on upload endpoints.
