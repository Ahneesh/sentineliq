# SentinelIQ v0.4.0 — Scenario Administration

**Release date:** 2026-07-14  
**Release theme:** Configuration-driven surveillance governance

## Highlights

- Added the Surveillance workspace and Scenario Catalogue.
- Added detailed scenario pages with Overview, Logic, Thresholds, Data, Applicability, AI Knowledge and Audit tabs.
- Added relational scenario, parameter, dataset-requirement and audit models.
- Added five independently authored market-abuse scenario seeds: Spoofing, Layering, Wash Trading, Momentum Ignition and Marking the Close.
- Added scenario lifecycle status transitions and audit capture.
- Added scenario metrics for Draft, Review, Approved and Production states.

## Database changes

Alembic revision `20260714_0002` adds:

- `scenarios`
- `scenario_parameters`
- `scenario_dataset_requirements`
- `scenario_audits`

Run `alembic upgrade head` before starting the backend.

## API changes

- `GET /api/scenarios`
- `GET /api/scenarios/metrics`
- `GET /api/scenarios/{scenario_id}`
- `POST /api/scenarios`
- `PATCH /api/scenarios/{scenario_id}/status`

## Known limitations

- Scenario parameters are read-only in the first UI release.
- Maker-checker permissions are represented by lifecycle states but authentication/RBAC is not yet enforced.
- Detection logic is descriptive configuration; executable rules arrive in v0.5.0.
- Seed scenarios are independently authored demonstrations, not regulatory advice or production-calibrated models.
